The Real-World Crisis

Problem: Water Loss & Fragile Automation

Why traditional systems fail during critical pipeline ruptures.

The Crisis
  • 20% to 40% Water Loss: Municipal distribution mains lose massive amounts of clean water to undetected leaks.
  • SCADA Alert Fatigue: Existing sensors sound alarms but cannot take remedial isolation action.
  • Manual Delay: Physical crews take hours to reach remote valves.
Why Scripts Fail & Why We Need Agents
  • No Verification: Scripts execute commands and assume the pipe is closed without checking post-action telemetry.
  • Crash on Jam: If a valve mechanically jams, static scripts halt.
  • AquaAgent Solution: An autonomous agent that observes feedback, adapts to backup valves, and verifies recovery.
Problem & Opportunity Target: Municipal Grids, Smart Campuses, Industrial Facilities

Physics & Safe Tools

Leakage Logic & Structured Tool Registry

Mathematical thresholds driving safe, typed tool execution.

Deterministic Classification Logic
LossPercentage = (Flow_In - Flow_Out) / Flow_In

🟢 NORMAL: Loss < 10% & Pressure ≥ 2.5 bar
🟡 MEDIUM: Loss ≥ 10%
🔴 HIGH: Loss ≥ 25% OR Pressure < 2.0 bar
Structured Tool Registry
  • getSensorData(): Live telemetry reading
  • analyzeLeakage(): Fluid mass balance calculation
  • controlValve(id, action): Physical actuator control
  • verifyRecovery(): Post-action hydraulic check
  • sendAlert(msg, severity): Emergency dispatch
Safety Boundary No blackbox hallucinations • 100% Structured Tool Execution
🔥 Flagship Feature

Failure Detection + Dynamic Adaptation

How AquaAgent self-heals when physical actuators fail.

1. Actuator Fault Intercepted
  • High leak detected: In: 100 L/s, Out: 58 L/s, Press: 1.6 bar.
  • Agent commands primary Valve 1 to close.
  • Valve 1 mechanically jams and returns hardware fault.
  • Agent emits FAILURE and traps error gracefully.
2. Dynamic Re-Planning & Recovery
  • AdaptationEngine triggers alternative isolation plan.
  • Agent commands backup redundant Valve 2.
  • Valve 2 closes successfully $\rightarrow$ leak isolated.
  • Agent executes verifyRecovery(): Loss drops to $2.5\%$, pressure normalizes to $3.15\text{ bar}$.
  • Final Status: ADAPTED_AND_RESOLVED.

Robustness & Quality

Fail-Safe Human Escalation & Testing

Guaranteed safety boundaries and automated test validation.

Both Valves Jammed (Fail-Safe Protocol)
  • Valve 1 fails $\rightarrow$ Agent adapts to Valve 2 $\rightarrow$ Valve 2 also fails.
  • Agent recognizes automated isolation is impossible.
  • Dispatches critical alert to municipal emergency repair crews.
  • Logs incident to SQLite database $\rightarrow$ Status: ESCALATED.
